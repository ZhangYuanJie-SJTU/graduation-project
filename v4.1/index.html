数据预处理关键决策

ECG → PPG 信号转换 (核心技术点)

为什么要转换？ MIT-BIH是ECG数据（尖峰R波），而MAX30102采集PPG信号（圆滑收缩峰）。训练数据必须与部署数据同分布。

如何转换？

• IR通道 = ECG归一化 × 60000 + 50000 (主信号)

• Red通道 = ECG归一化 × 50000 + 40000 + 噪声 (辅助)

• ADC范围映射到18位: 0 ~ 262143

4秒窗口选择理由 (400采样点)

✓ 覆盖3-5个完整心跳周期

✓ 足以捕捉心率变异性(HRV)特征

✓ 符合实时检测响应时间要求

✓ 100Hz × 4s = 400点，计算量适中

15标注 → 6类映射规则

• V/A(早搏标注) → 4-PREMATURE

• F(融合波) → 3-ARRHYTHMIA

• HR>100 → 1-TACHYCARDIA

• HR<60 → 2-BRADYCARDIA

• RR>1.5s → 5-PAUSE

• SDNN>50ms → 3-ARRHYTHMIA

ECG波形生成算法 (重要说明)

注意: 小程序上显示的心电波形是基于心率值和raw_ir强度模拟生成的P-QRS-T特征波形，非真实ECG。

R(t) = A×exp(-(t-π)²/0.1)
T(t) = 0.2A×exp(-(t-π-1.5)²/0.5)
A = 100×(0.8+log₁₀(raw_ir)/10)
