## 01 · 项目背景

### 为什么要做这个系统？

心律失常 × 独居老人 × 不可及时发现 = 生命的隐形威胁

**严峻现实**

心血管疾病已成为影响中老年人群健康的首要因素。心房颤动等心律失常不仅引发心悸、胸闷，更会显著增加**卒中、心力衰竭甚至心源性猝死**的风险。

- 老年人心律失常漏诊率（传统院内检查）：**70%+**

**独居困境**

独居老人发生心脏异常时**无法及时获得救助**。传统院内心电图时间短、场景受限，难以捕捉日常阵发性心律失常事件，导致漏诊或延误诊治。同时还面临**跌倒**等意外伤害风险。

**解决思路**

设计一套**低成本、低侵入性**的可穿戴多体征监护系统，实现：

- 心率/血氧/体温连续监测
- 心律失常AI智能识别
- 跌倒检测与自动报警
- GPS定位追踪
- 云端数据 + 小程序远程监护

### 技术发展现状

**国内外已有探索**

基于PPG和ECG的可穿戴设备对房颤等心律失常检测灵敏度和特异度普遍在**85%以上**，PPG+ECG融合算法系统可达**90%以上**识别准确率。跌倒检测已从单纯阈值判定向多传感器融合与机器学习演进，识别率提升至90%以上，误报率控制在5%以内。

**现有不足**

1. 多集中单一参数监测，缺乏多维特征深度挖掘
2. 舒适性与信号质量的矛盾难以兼顾
3. 针对心律失常的专用预警模型不完善
4. 数据安全与隐私保护不足

## 03 · 硬件迭代

### 四代硬件，百块打样的进化之路

从10cm厚重PCB到5cm超薄FPC，每一次迭代都是对穿戴体验的极致追求

**第一代 · 探索期 — 传统PCB方案**

- 规格：10cm x 10cm x 1.2mm | 模块化元件 | 50g 18650电池 | 背带式佩戴
- 问题：体积大、重量重，心率温度测量不准确，佩戴体验差

**第二代 · 优化期 — 缩小尺寸，优化资源**

- 规格：7cm x 7cm x 1mm | 排版优化 | 25g 电池 | 臂戴式佩戴
- 迭代方向：减小PCB尺寸与重量，优化IIC资源分配
- 问题：仍然较重，佩戴不稳定

**第三代 · 突破期 — 子母式结构 + FPC连接**

- 规格：5cm+3cm 子母板 | FPC软排线 | 贴片元件 | 腕戴+指戴
- 迭代方向：结构创新为子母式，模块化元件替换为贴片元件，指戴式采集大幅提升心率精度
- 问题：FPC软排线导致IIC通信不稳定易受干扰

**第四代 · 最终版 — 全FPC柔性方案**

- 规格：5cm x 3cm x 0.2mm | 纯FPC柔性板 | 贴片元件 | 350mAh锂电池 | 肌贴式佩戴
- 迭代方向：大幅降低重量和尺寸，穿戴体验质的飞跃
- 优势：几乎无感佩戴，电池容量小的问题通过软件低功耗模式弥补

### 四代对比一览

| 指标 | 第一代 | 第二代 | 第三代 | **第四代(最终)** |
|:---|:---|:---|:---|:---|
| 尺寸 | 10x10cm | 7x7cm | 5x5+3x3cm | **5x3cm** |

```c
// 线程安全的数据读取
SystemData_t read_system_data(void) {
    SystemData_t data = {0};
    if (xSemaphoreTake(g_data_mutex, portMAX_DELAY) == pdTRUE) {
        data = g_sys_data;
        xSemaphoreGive(g_data_mutex);
    }
    return data;
}
```

## 07 · 核心算法 I — Maxim心率血氧检测算法

从原始PPG信号到精准心率值，四级信号处理 + 卡尔曼滤波平滑

### 算法处理流水线

原始PPG(IR/Red信号) → 去直流(减均值) → 移动平均(4点滤波) → 一阶差分(斜率突出) → Hamming窗(带通滤波) → 峰值检测(自适应阈值) → RR间期(异常值剔除) → 心率计算(分段校准) → 卡尔曼滤波(平滑输出)

### 信号预处理四步法

1. **去直流**：计算IR信号均值，移除直流分量
2. **移动平均**：4点滑动窗口滤波，削弱高频噪声
3. **一阶差分**：计算相邻采样点差值，突出脉搏波变化的斜率
4. **Hamming窗**：加权滤波实现带通滤波特性，同时反向信号

```c
// Hamming窗系数
const uint16_t auw_hamm[31] = { 41, 276, 512, 276, 41 };

// 4点移动平均滤波
for (k = 0; k < BUFFER_SIZE - MA4_SIZE; k++)
    an_x[k] = (an_x[k]+an_x[k+1]+an_x[k+2]+an_x[k+3]) / 4;
```

### 峰值检测与心率计算

- **自适应阈值**：基于信号平均绝对偏差(MAD)动态调整
- **异常值剔除**：偏离中位数超过30%的间隔自动排除
- **心率公式**：`HR = 6000 / 平均间隔(样本点)`

**分段校准系数**

| 心率范围 | 校准系数 |
|:---|:---|
| < 65 bpm | × 0.92 |
| 65 ~ 100 bpm | × 0.90 |
| > 100 bpm | × 0.88 |

### 血氧饱和度(SpO2)计算

基于Beer-Lambert定律，通过红光(660nm)和红外光(880nm)在含氧与脱氧血红蛋白中的吸收差异计算：

```
R = (AC_red / DC_red) / (AC_ir / DC_ir)
SpO2 = f(R)  // 查找表法
```

SpO2查找表包含184个预计算值，基于R值线性插值获取最终血氧值。

**精度指标**：心率 ±2 bpm | 血氧 ±2%

### 卡尔曼滤波优化

为提高心率测量的**稳定性**，引入卡尔曼滤波进行平滑处理，并增加**突变抑制**机制：

```c
// 卡尔曼滤波参数
const float kf_q = 0.01f;  // 过程噪声
const float kf_r = 10.0f;  // 测量噪声

// 预测步
float kf_p_pred = kf_p + kf_q;
float kf_k = kf_p_pred / (kf_p_pred + kf_r);  // 卡尔曼增益

// 突变抑制：心率变化超过阈值时降低增益
float diff = n_heart_rate - kf_x;
if (fabs(diff) > 20.0f) kf_k *= 0.1f;     // 剧烈突变
else if (fabs(diff) > 10.0f) kf_k *= 0.3f; // 中等变化

// 更新步
kf_x = kf_x + kf_k * (n_heart_rate - kf_x);  // 状态估计
kf_p = (1.0f - kf_k) * kf_p_pred;             // 协方差更新
```

效果：有效抑制单次测量的跳变，输出平滑稳定的心率值

## 08 · 核心算法 II — 基于TFLite的心律失常AI检测

MIT-BIH数据集训练 → 1D-CNN模型 → INT8量化 → ESP32-S3端侧实时推理

### 技术路线全景

MIT-BIH(数据集) → 重采样(360→100Hz) → ECG→PPG(信号转换) → 1D-CNN(模型训练) → INT8量化(29.41KB) → ESP32部署(实时推理)

### 训练数据集：MIT-BIH心律失常数据库

| 项目 | 说明 |
|:---|:---|
| 发布机构 | MIT + 贝斯以色列医院 |
| 记录总数 | 48条 × 30分钟 = 24小时 |
| 采样率 | 360 Hz / 2通道 |
| 心搏总数 | ~110,000个 |
| 标注类型 | 15种以上（专家标注） |
| 被引用 | 1000+ 篇论文 |

**数据预处理**

- **重采样**：360Hz → 100Hz (线性插值)
- **窗口分割**：400采样点 = 4秒窗口，覆盖3-5个心跳周期
- **ECG→PPG转换**：IR通道(主信号) + Red通道(带噪声辅助)
- **标签映射**：15种标注 → 6类临床分类
- **最终数据集**：(22,030, 400, 2) — 22030样本 × 400时间步 × 2通道

### 六类心律失常分类

| 类别 | 名称 | 说明 |
|:---|:---|:---|
| 0 | 正常心律 | NORMAL · 60-100bpm · RR间期规则 |
| 1 | 心动过速 | TACHYCARDIA · 心率 > 100bpm |
| 2 | 心动过缓 | BRADYCARDIA · 心率 < 60bpm |
| 3 | 心律不齐 | ARRHYTHMIA · RR间期不规则(如房颤) |
| 4 | 早搏 | PREMATURE · 提前出现的异位搏动 |
| 5 | 漏搏 | PAUSE · RR间期 > 1.5秒 |

### 1D-CNN 网络架构

```
Input (400, 2) — 4秒 × IR+Red双通道
  ↓
Conv1D 16 filters, k=5, ReLU → MaxPool(4) → (100, 16)
  ↓
Conv1D 32 filters, k=5, ReLU → MaxPool(4) → (25, 32)
  ↓
Conv1D 64 filters, k=3, ReLU → MaxPool(4) → (6, 64)
  ↓
Conv1D 32 filters, k=3 → GAP → (32,)
  ↓
Dense 32 + Dropout(0.3)
  ↓
Output: Dense 6 + Softmax → 6类概率分布
```

- 总参数量: ~16,400
- 量化后: 29.41KB
- 推理时间: <50ms

## 09 · 核心算法 III — 多级判定跌倒检测算法

冲击检测 + 静止检测 + 姿态变化 = 三重条件综合判定，ISR中断实时响应

### 算法流程

1. **数据采集 (10Hz)**：获取三轴加速度(ax, ay, az)，计算合加速度: a = sqrt(ax² + ay² + az²)
2. **冲击检测**：检测加速度突变: a > **2.5g** → 记录冲击时间点
3. **静止检测**：冲击后检测是否进入静止状态: 加速度变化 < **0.2g** 持续 > **1秒**
4. **姿态变化检测**：计算姿态角度变化: 角度变化 > **45°** 判定为姿态显著变化
5. **综合判定**：冲击 + 静止 + 姿态变化 = 跌倒确认 → 触发LED闪烁 + 蜂鸣器 + 云端推送 → 按KEY3可解除报警

### 关键阈值参数

| 参数 | 值 |
|:---|:---|
| 冲击加速度阈值 | 2.5g |
| 静止检测条件 | 0.2g / 1s |
| 姿态角变化阈值 | 45° |

### 核心代码 (简化)

```c
bool fall_detect(bool reset) {
    static float last_accel = 0;
    static int still_count = 0;
    static bool impact_detected = false;

    // 计算合加速度
    float total = sqrtf(ax*ax + ay*ay + az*az);

    // Step 2: 冲击检测 (>2.5g)
    if (total > 2.5f && !impact_detected) {
        impact_detected = true;
    }

    // Step 3: 冲击后静止检测
    if (impact_detected) {
        if (fabsf(total - last_accel) < 0.2f) {
            still_count++;
            if (still_count > 10) return true; // 跌倒确认!
        } else { still_count = 0; }
    }
    last_accel = total;
    return false;
}
```

### 关键技术难点与解决方案

**波形卡顿**

- 问题：每3-5秒出现卡顿
- 原因：200ms轮询无条件setData与Canvas动画线程竞争
- 方案：数据变化检测，仅在数据真正变化时调用setData
- 效果：优化前 5次/秒 → 优化后 0次/秒(无变化时)

**状态跳变**

- 问题：在线/离线状态反复跳动
- 原因：网络波动导致API响应不稳定
- 方案：计数器防抖机制，连续3次确认才变更，网络错误5次

**记录冗余**

- 问题：短时间内大量相同异常记录
- 原因：设备端重复上报+小程序未去重
- 方案：30秒合并策略，相同类型只保留一条，最多存20条

### ECG波形生成算法

基于心率值和红外信号强度，模拟生成具有**P-QRS-T特征**的ECG波形：

- **R波(主波峰)**：R(t) = A × exp(-(t-π)²/0.1)
- **T波(复极波)**：T(t) = 0.2A × exp(-(t-π-1.5)²/0.5)
- **综合波形**：ECG(t) = R(t) + T(t) + noise + baseline
- 振幅自适应系数 A = 100 × (0.8 + log₁₀(raw_ir)/10)

## 14 · 核心创新点

### 五大创新，从算法到产品的全方位突破

**创新一：边缘AI心律失常检测**

在可穿戴设备上实现基于TFLite Micro的**6类心律失常实时分类**。INT8量化模型仅29.41KB，推理时间<50ms，**无需联网即可完成诊断**，保护用户隐私的同时降低延迟。

**创新二：四代硬件极致迭代**

从10cm传统PCB到**5cm×3cm×0.2mm FPC柔性板**，前后8块设计、100块打样。最终实现**肌贴式近乎无感佩戴**，聚酰亚胺基材确保弯折可靠性。

**创新三：FreeRTOS双核并发架构**

充分利用ESP32-S3双核特性，**Core 1专注高实时性传感器+AI推理**，Core 0处理UI/通信等非实时任务。8级任务优先级精细设计，SOS报警优先级最高(15级)确保紧急响应。

**创新四：三级智能功耗管理**

活跃-待机-深度休眠三级模式，基于手指检测的**自适应状态切换**。日常佩戴场景续航从3.3小时提升至**12小时(提升300%)**，深度休眠功耗仅~10μA。

**创新五：监测-分析-预警-通知 全链路闭环**

构建**设备端(ESP32-S3) → 云端(OneNET MQTT) → 移动端(微信小程序)**的完整数据通路。设备端多传感器采集+边缘AI推理，云端数据存储+可视化，小程序端200ms实时刷新+40fps波形绘制+报警推送，形成完整的**居家健康监护解决方案**。
