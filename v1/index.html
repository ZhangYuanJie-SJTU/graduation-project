01 · 项目背景

为什么要做这个系统？

心律失常 × 独居老人 × 不可及时发现 = 生命的隐形威胁

⚠ 严峻现实

心血管疾病已成为影响中老年人群健康的首要因素。心房颤动等心律失常不仅引发心悸、胸闷，更会显著增加卒中、心力衰竭甚至心源性猝死的风险。

70%+
老年人心律失常漏诊率（传统院内检查）

🚶 独居困境

独居老人发生心脏异常时无法及时获得救助。传统院内心电图时间短、场景受限，难以捕捉日常阵发性心律失常事件，导致漏诊或延误诊治。

同时还面临跌倒等意外伤害风险，跌倒引发的骨折、颅脑损伤是老年人失能和死亡的重要原因。

💡 解决思路

设计一套低成本、低侵入性的可穿戴多体征监护系统，实现：

  • ✓ 心率/血氧/体温连续监测
  • ✓ 心律失常AI智能识别
  • ✓ 跌倒检测与自动报警
  • ✓ GPS定位追踪
  • ✓ 云端数据 + 小程序远程监护

技术发展现状

🏠 国内外已有探索

基于PPG和ECG的可穿戴设备对房颤等心律失常检测灵敏度和特异度普遍在85%以上，PPG+ECG融合算法系统可达90%以上识别准确率。

跌倒检测已从单纯阈值判定向多传感器融合与机器学习演进，识别率提升至90%以上，误报率控制在5%以内。

❌ 现有不足

  • 1. 多集中单一参数监测，缺乏多维特征深度挖掘
  • 2. 舒适性与信号质量的矛盾难以兼顾
  • 3. 针对心律失常的专用预警模型不完善
  • 4. 数据安全与隐私保护不足

🎵 信号预处理四步法

1. 去直流：计算IR信号均值，移除直流分量

2. 移动平均：4点滑动窗口滤波，削弱高频噪声

3. 一阶差分：计算相邻采样点差值，突出脉搏波变化的斜率

4. Hamming窗：加权滤波实现带通滤波特性，同时反向信号

// Hamming窗系数 const uint16_t auw_hamm[31] = { 41, 276, 512, 276, 41 }; // 4点移动平均滤波 for (k = 0; k < BUFFER_SIZE - MA4_SIZE; k++) an_x[k] = (an_x[k]+an_x[k+1]+an_x[k+2]+an_x[k+3]) / 4;

📈 峰值检测与心率计算

自适应阈值：基于信号平均绝对偏差(MAD)动态调整

异常值剔除：偏离中位数超过30%的间隔自动排除

心率公式：

HR = 6000 / 平均间隔(样本点)

血氧饱和度(SpO2)计算

基于Beer-Lambert定律，通过红光(660nm)和红外光(880nm)在含氧与脱氧血红蛋白中的吸收差异计算：

R = (ACred / DCred) / (ACir / DCir) SpO2 = f(R) // 查找表法

SpO2查找表包含184个预计算值，基于R值线性插值获取最终血氧值

卡尔曼滤波优化

为提高心率测量的稳定性，引入卡尔曼滤波进行平滑处理，并增加突变抑制机制：

// 卡尔曼滤波参数 const float kf_q = 0.01f; // 过程噪声 const float kf_r = 10.0f; // 测量噪声 // 预测步 float kf_p_pred = kf_p + kf_q; float kf_k = kf_p_pred / (kf_p_pred + kf_r); // 卡尔曼增益 // 突变抑制：心率变化超过阈值时降低增益 float diff = n_heart_rate - kf_x; if (fabs(diff) > 20.0f) kf_k *= 0.1f; // 剧烈突变 else if (fabs(diff) > 10.0f) kf_k *= 0.3f; // 中等变化 // 更新步 kf_x = kf_x + kf_k * (n_heart_rate - kf_x); // 状态估计 kf_p = (1.0f - kf_k) * kf_p_pred; // 协方差更新

效果：有效抑制单次测量的跳变，输出平滑稳定的心率值

09 · 核心算法 III

多级判定跌倒检测算法

冲击检测 + 静止检测 + 姿态变化 = 三重条件综合判定，ISR中断实时响应

算法流程

Step 1 · 数据采集 (10Hz)

获取三轴加速度(ax, ay, az)，计算合加速度: a = sqrt(ax² + ay² + az²)

▼
Step 2 · 冲击检测

检测加速度突变: a > 2.5g → 记录冲击时间点

▼
Step 3 · 静止检测

冲击后检测是否进入静止状态: 加速度变化 < 0.2g 持续 > 1秒

▼
Step 4 · 姿态变化检测

计算姿态角度变化: 角度变化 > 45° 判定为姿态显著变化

▼
综合判定：冲击 + 静止 + 姿态变化 = 跌倒确认

触发LED闪烁 + 蜂鸣器 + 云端推送 → 按KEY3可解除报警

关键技术难点与解决方案

波形卡顿

问题：每3-5秒出现卡顿

原因：200ms轮询无条件setData与Canvas动画线程竞争

方案：数据变化检测，仅在数据真正变化时调用setData

优化前: 5次/秒 优化后: 0次/秒(无变化时)

状态跳变

问题：在线/离线状态反复跳动

原因：网络波动导致API响应不稳定

方案：计数器防抖机制，连续3次确认才变更，网络错误5次

记录冗余

问题：短时间内大量相同异常记录

原因：设备端重复上报+小程序未去重

方案：30秒合并策略，相同类型只保留一条，最多存20条

ECG波形生成算法

基于心率值和红外信号强度，模拟生成具有P-QRS-T特征的ECG波形：

R波(主波峰)：R(t) = A × exp(-(t-π)²/0.1)

T波(复极波)：T(t) = 0.2A × exp(-(t-π-1.5)²/0.5)

综合波形：ECG(t) = R(t) + T(t) + noise + baseline

振幅自适应系数 A = 100 × (0.8 + log₁₀(raw_ir)/10)
